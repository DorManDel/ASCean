Dense SoA · Swap-and-Pop

Choose a fish, delete it and watch only the last active row move. The EntityID and the other fish's handle do not change.

This is an isolated conceptual model of E-003. The existing reference World does not yet implement generational handles.

Stable Slots / Free List

Rows may move in hot SoA; Slots stay in the slot table. Deleted slots are recycled with incremented generations.

What is the complexity?

Handle check: O(1) Swap-and-Pop: O(1)* Active scan: O(n) Slot recycling: O(1)

*Assuming fixed-size columns and no additional expensive component cleanup. No real timings have been measured.

Use circular buffers where they fit

Event Queue · Sensor History · Motion History · Telemetry

Single-parent Blueprint extends

One config parent per Blueprint. No limit of two levels by default, but detect cycles and warn about unusually long chains. The UML triangle points toward the parent above.
