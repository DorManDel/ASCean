# Source-preserving prototype archive

The two interactive HTML documents in this directory were supplied by the project owner on 2026-11-13:
- `aquarium-mechanics-archive.html`: prior multi-topic Aquarium Mechanics Lab (v10).
- `species-genome-lab.html`: prior ASCean Species & Genome Lab (v0.8).

Only a tiny hash/anchor navigation adapter was appended to each copy so Hub cards can deep-link to a section. The originals remain in the conversation uploads and were **not modified**.

These are exploratory UI prototypes and contain many hypothetical biological parameters. Their presence in the repository does not constitute scientific validation or integration into the `World` engine.
