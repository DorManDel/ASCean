What's the trade-off?

  • Quantization maps a real number to a finite integer range.
  • 8 bits stores 256 distinct codes; 16 bits stores 65,536.
  • Snapshot storage can be smaller; precision is lost.
  • Full memory includes Map, grid, genomes, renderer and overhead.

World / 02

Fixed Simulation Ticks vs Display Refresh

Refresh describes how often the screen *can* draw; ticks describe how the world advances in time.

Read the comparison

  • Time-based: 40 cm/s independent of frame rate.
  • Fixed snapshot: also 40 cm/s, but positions update in discrete ticks.
  • Wrong per-frame: speed changes if FPS assumption changes. It is deliberately incorrect.

The Hz slider is a mathematical scenario. Only the FPS metric in Spatial Search measures this browser.

Biological Hybrid Growth

  • Age and species affect potential structural growth.
  • Nutrition and environment affect realized growth.
  • Stored food, reserves and reproductive mass can change without instant length changes.
  • Species research, digestion and mass-balance laws remain open.
Project / 01

Component System & Decisions

Each system owns a clear contract. Bootstrap initializes dependencies; event routing and experiments remain separate from scientific laws.

Bootstrap / DI

Resolve module dependencies, initialize in order, dispose in reverse order. No giant global class.

Event Hub

Typed domain events with scoped cleanup. High-rate physics uses direct data access, not per-fish events.

Snapshots

Versioned World, registry, clock and PRNG state, plus experiment parameters. Reproducible replay is a milestone requirement.

Mechanism Contracts

Initialize, update (if needed), dispose, serialize/restore, tests and benchmark obligations.

Scientific Data
