# ASCean Decision Register (2026-11-13)

## Accepted architecture
- ADR-001 NEW PROJECT: ASCean (ASCII Ocean) lives in its own repository; MobiLab and original ASCuarium remain untouched.
- ADR-002 MONOREPO: Ocean Simulator and Mechanics Lab use shared source packages, with separate UIs.
- ADR-003 LANGUAGE: TypeScript/JavaScript first. C++ / WebAssembly only after profiling.
- ADR-004 DATA: SoA TypedArrays for numeric hot data; stable Fish ID separated from array slot; swap-and-remove.
- ADR-005 WORLD: X=100m width, Y=50m height, Z=30m depth; internal cm, seconds, grams.
- ADR-006 CAMERA: 2D side view over 3D positions; spatial query and eventual collision are 3D.
- ADR-007 ENVIRONMENT: marine ocean default, separate freshwater and brackish habitats; zebrafish research occurs in freshwater.
- ADR-008 GROWTH: Biological Hybrid Growth (species, developmental stage, inherited potential, long-term nutrition, environment and health).
- ADR-009 SIZE: store Standard Length (SL) and Total Length (TL) separately; eventually anatomical parts, body height and width.
- ADR-010 MASS: bodyMassG derived from non-overlapping structural, reserve, gut and reproductive compartments; components require scientific models.
- ADR-011 BIO CLOCK: configurable biological time, distinct from rendering and physical simulation time.
- ADR-012 VERIFICATION: mechanic prototype + source implementation + tests + owner approval + PCM checkpoint before integration or release.

## Provisional implementation choices
- P-001 30 TPS fixed physics baseline; simple reflected velocity.
- P-002 Float32 positions/velocities and numeric energy (not yet metabolism).
- P-003 JS Map IDs and sparse 3D grid with uniform cells.
- P-004 Canvas2D + ASCII-like glyphs; eventual glyph atlas/WebGL to be evaluated.
- P-005 3D sphere for perception broad checks; real collision shape and sensing modalities pending.
- P-006 No memory packing/quantization inside simulation until evidence supports benefit.

## Not decided / not implemented
- Nutrition and material/energy ledgers, bowel contents and waste.
- True hydrodynamics, buoyancy, water pressure/light effects and chemistry fields.
- Species-specific anatomy, collision injury and reconstruction of damaged ASCII graphics.
- Scientific genetics and inheritance; FishDex sourcing & versioning.
- Behavioral motives (avoid/curious/territorial/predatory), perception, memory and learning.
- Evolution, reproduction and lifespan coefficients.
- Benchmarked population, frame-time and RAM targets for real mobile hardware.

This file is the accepted design contract; exact biological equations must be calibrated from reputable primary sources, not generated by AI on intuition.
