# PCM checkpoint handoff

The private ProjectContextManager repository is a *curated evidence registry*, not a log of all chats. The ASCean project record is proposed in a separate review PR and must not be published as a public Pages site.

At each meaningful ASCean milestone:
1. Pin exact ASCean branch, commit SHA, PR link, UI screenshot and observed tests.
2. Separate code source verified, runtime tested, design proposal and scientifically calibrated.
3. Update PCM projects/ascean/HANDOFF.md, DECISIONS.md, TASKS.md and CHANGELOG.md with deltas only; use snapshots for substantial checkpoints.
4. Keep global EXECUTION_BOARD.md as the canonical priority queue, no duplicated independent backlogs.
5. Run PCM catalog builder and validator, open a private reviewable PR, do not merge without owner permission.
6. Record verified release SHA and protected access checks after approval. Never invent time logs or token usage.

Keep the original projects/ascuarium PCM entry as history of the old project, not as implementation evidence for ASCean.
